# UCSD Pangenome Browser

The UCSD Pangenome Browser is a interactive Pangenome that provide rapid search and display of the pangenome graph with annotations and tracks. 

The Human Pangenome Reference Consortium (HPRC) released the first draft human pangenome in 2023, reducing the reference bias inherent to representing human genetic variation with a single linear genome. As pangenome graphs continue to grow in scale and scope, and their use in downstream analyses expands accordingly, tools for visualizing the pangenome and mapping between pangenome graphs and existing annotations and tracks are critical. The UCSD Pangenome Browser addresses this by combining existing pangenome visualization tools to provide rapid search and display of the pangenome graph. The Pangenome Browser supports search by gene name or by genomic regions, overlays tracks on various graph types, and enables interactions between the pangenome graph and linear tracks.

UCSD Pangenome Browser: [https://pangenome.ucsd.edu/](https://pangenome.ucsd.edu/)
